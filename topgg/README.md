# Top.gg listing copy

- Copy `short-description.txt` into the short description field.
- Copy the contents of `description.html` into the long description field. Paste the HTML source, not the browser-rendered text.
- Check Top.gg's preview before saving, including the narrow/mobile layout. The design uses inline CSS; the editor may sanitize some styling.

The banner uses the public repository's existing image. The description needs no JavaScript, embeds, or new image hosting.

This is prepared listing copy. Committing these files does not update the live Top.gg listing.
